# 先里后外装箱顺序

在 2025 可达性模式中，打开“设置”，可选择“装箱顺序优先规则”：

- 自动：按已应用工位中机械臂基座所在侧判断外侧。
- 手动：指定托盘的 +X、-X、+Y 或 -Y 为外侧。

例如机械臂位于 -Y 侧时，该侧为外侧。同层箱子优先从 +Y 远侧向 -Y 近侧放置。托盘长边为 X，短边为 Y；旋转工位后仍以托盘坐标为准。托盘输入毫米会换算为与工位一致的米制坐标。

规则按以下关系执行：

1. 托盘内首先满足支撑、稳定、边界和允许接近方向的遮挡约束。
2. 当前可放置的候选中，优先较低底面；底面相同时优先远侧，再按原顺序打破并列。
3. 启用机器人完整校验后，对该顺序验证 IK、机器人/工具/携箱碰撞以及抓取、搬运、放置、撤离路径。
4. 优先顺序验证失败时，最多再尝试一次原规则备用顺序，并重新验证；仍失败则拒绝候选方案。采用备用顺序时，界面、日志和 JSON 会注明例外。此策略不穷举所有可能的机器人操作顺序。

“允许的接近方向”和“里外基准”独立。例如只勾选 +Z，表示最后从上向下放箱，同层仍可按水平方向先里后外排列。

如果没有应用工位、机械臂基座投影在托盘内，或外侧存在对角歧义，程序不会猜测机械臂所在侧。请配置工位或手动指定外侧；未确定基准时会明确提示并保留原可行顺序。

这一规则在离线规划中生成执行顺序。执行时已经放置的箱体固定，不通过移动已放箱体实现换序。设置修改后须重新计算，历史结果不会被直接改写。

结果 JSON 的 `robot_diagnostics.sequencing_policy` 保存请求的 `outside_side`、实际规则 `name`，以及 `fallback_used`、`fallback_reason`。

CLI 示例：

```powershell
python main.py --algorithm robot2025 --input-json boxes.json --outside-side=-Y --no-show
```

使用 `--robot-scene` 时，默认 `--outside-side auto` 自动读取工位；不提供工位可用手动外侧。打开工位界面时，程序会先载入机器人运行库，再导入 Qt，以避免 Windows DLL 初始化顺序冲突。更新后需退出旧程序再启动。
