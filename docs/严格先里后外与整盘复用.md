# 严格先里后外与整盘复用

当工位自动推导或手动指定外侧后，按托盘、箱底高度从低到高、同底高度箱体中心从远到近执行。支撑、碰撞、边界、允许姿态与最终稳定性仍须满足；失败不会取消外侧基准或退回先外后里。

模板生成时将负X/负Y外侧对应的新布局镜像到远侧角点；原箱体尺寸和允许姿态不改变。原有共享顶点/对齐边规则检查最终布局是否与托盘角点连通，不再作为必须依照原模板插入顺序执行的条件。实际交付顺序逐箱检查支撑与碰撞。

验证缓存以完整工位/模型/工具/规划参数和托盘内有序箱体几何为键，仅保存完整通过的托盘。箱号相同但位置、姿态或顺序改变不会复用。编号变化可以复用并重新标注轨迹所属托盘。一次验证前先固定可复用结果，再检查新增/变化托盘；最终报告重新按实际托盘执行顺序拼接完整轨迹。

前缀缓存容量至少512条，并覆盖当前托盘的两倍箱数，避免256条缓存处理600多箱时不断淘汰。失败结果不作为可行结果缓存。缓存仍仅在当前计算实例内有效，不跨重启恢复。

日志新增候选编号、变化托盘优先验证、整盘复用数量和箱数。最终未全部通过时不生成成功结果或可回放轨迹文件。

2026-11-26：真实668箱数据的严格几何预检查保留608箱/11盘，60箱进入GA。独立全路径试算使用20种群、5代上限、2代停滞，最多90分钟；这些参数只用于该次试算，没有覆盖界面默认配置。

## 初步结果优先

2025设置新增“初步结果优先：已验证托盘封盘，余箱开新盘（可能增加盘数）”，默认开启；可关闭以继续搜索向已有托盘补箱。API保持默认关闭以兼容原调用，run_packing_job参数为robot_seal_verified_pallets。封盘模式只限制余箱候选位置，不删除箱体，不跳过几何、支撑或完整路径验证。为尽快得到可回放样例，独立封盘试算启用该模式。

## 吸盘目标包络前置筛选

真实余箱失败样例：箱324可求IK，但600×800吸盘会碰到已放箱591。当前生成候选位置时即使用同一工具几何和TCP定义进行精确OBB相交筛选，并按最终严格顺序复核变化托盘，避免将明显工具干涉的布局送入完整路径规划。该筛选不替代机械臂连杆、携箱和整条路径验证。

为取得首个完整样例，对已通过目标包络筛选的13盘668箱几何候选，使用两个独立进程进行每盘完整运动验证；每盘都从配置初始构型开始，与现有独立托盘工位假设一致。只有所有托盘和回放结构校验全部通过后才发布成功JSON、CSV、垛型图。该并行调度用于本次独立试算；GUI仍使用现有后台计算与整盘缓存。
