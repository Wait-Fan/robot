# 可视化工位与机械臂选择

双击项目根目录的`start_workcell_editor.bat`，或在工作台点击“工位布局”。启动脚本预选现场FANUC型号；右上方型号框可随时选择：

- EC66：用户提供的实验室机械臂和吸盘模型。
- FANUC R-2000iC/210L：用户提供的`fanuc-noetic-devel.zip`中对应的210L模型。

选择型号会同步更新实体模型、六轴限位、初始构型、TCP和碰撞模型。已有托盘、取箱台位置保留；点击“初始摆放”可放入一套未标定的虚拟布局，再自行调整。

## 看图摆放

1. 点击“俯视摆放”。左键选中托盘、取箱台或障碍物，拖动调整XY位置。
2. 右侧可精确修改XYZ（毫米）和绕Z的角度。Z可以为负数，参考原点为机器人模型底座`base_link`。
3. 右键拖动旋转视角，滚轮缩放，点击“适应画面”重新居中。
4. “机械臂”页的关节滑块调整起始构型。“检查当前初始姿态”只检查这一构型与环境、预览箱的碰撞，不等于整批路径验证。
5. “抓取与预览”页调整预览箱、工具、TCP偏置和抓取姿态。预览箱是显示参考；实际计算按各箱自身高度求取箱TCP。
6. 点“应用工位并启用机器人校验”。工位保存在`configs/workcell.json`。从独立编辑器应用后会打开工作台；选择输入数据后点击计算。工作台内部打开的编辑器会返回原窗口。

## 现场吸盘

用户已提供吸盘面尺寸600×800 mm。当前用长方体外包络模拟工具，法兰到吸附面的距离暂用250 mm，用户已确认其为可调暂定值。它用于碰撞检查，是保守的几何近似，不是现场吸盘的完整CAD模型。

该外包络沿FANUC `tool0` 的正Z方向安装，工具中心在距离H/2处，`packing_tcp`在距离H处。显示与检查器使用相同定义。`tool_definition`、`tool_status`会随工位及结果保存，当前状态明确为未标定。实际安装方向、支架形状和工具高度仍须现场核对。

FANUC模型的`base_link`是模型底座参考，文件还定义了高出670 mm的`base`坐标系。若现场读取的是控制器World/base坐标，必须先确认与模型参考系的换算。

## 计算含义

未启用“机器人完整校验”时，只进行开放侧箱体几何筛选。启用后，工作台把场景快照交给所选机械臂的IK、机器人/工具/携箱碰撞和抓取—搬运—放置—撤离路径检查；不会默默退回轻量检查。

结果JSON记录真实型号、工具参数、实际方向和关节路径。每次计算保存独立场景快照。工位尺寸与输入托盘尺寸不一致时会拒绝计算，要求重新打开工位更新。

工位预览或单一姿态无碰撞，不代表能覆盖整个托盘，也不代表实机验证。当前所有操作均在Windows离线计算，不连接或控制真实机械臂，不模拟吸附失效、载荷动力学与实机控制误差。

## 源文件

`robot_models/fanuc_r2000ic_support`保留用户压缩包中210L对应的原始Xacro、两套STL网格、源许可证和导入校验清单。可运行的URDF只展开前缀与数值表达式；没有执行归档里的ROS脚本。现有EC66文件保持不变。
