# 多个开放侧

打开2025工作台，点击“装箱设置”，勾选允许接近的侧面后点击确认。

- `+Z`：从上方往下接近。
- `+X`、`-X`、`+Y`、`-Y`：分别从相应侧面向目标接近。
- 可以多选，至少保留一项；默认仍为`+Z`，不支持穿过托盘从底部接近。
- 每个箱子可采用不同的允许方向。改变设置后，旧结果会提示需要重新计算。
- 取消设置保留原有选择。当前选择在本次工作台会话内有效。

轻量检查在已放箱体状态下选择无箱体遮挡的方向，并重新检查支撑、稳定和装箱几何约束。多方向顺序搜索允许回溯，最多探索10000个候选状态；预算耗尽不能证明问题无解。

命令行可重复传入方向，原来的单次参数用法保持兼容：

```powershell
python main.py --algorithm robot2025 --input-json examples/paper_two_phase.json --open-direction=+Z --open-direction=-X --open-direction=+Y --no-show
```

结果JSON的`robot_diagnostics.open_directions`记录允许侧，`checks`内每箱的`open_direction`记录所用方向。多方向结果不再用顶层单值`open_direction`代表全部箱子，该值为`null`；单方向结果保留旧单值。

通过`--robot-scene`启用EC66离线后端时，会对当前箱体的可用方向依次尝试搬运、放置和撤离。失败换侧时恢复该箱搬运前的仿真状态，既有箱体仍保持固定。实际通过路径验证的方向记录在`motion_verification.directions_by_box`与逐段轨迹中。整个序列受计算预算约束，未找到路径按未验证处理。

当前工作台的勾选设置仍对应轻量箱体模型；完整机械臂IK、夹具/连杆碰撞与轨迹检查通过命令行启用。任何结果均不代表实机验证。
