# 托盘左上角显示坐标

俯视托盘时，以装箱底面左上角为原点O：+X沿长边向右，+Y沿短边向下，+Z竖直向上。点击垛型卡片“俯视”或单托盘视图“俯视坐标”，可以查看这个方向。

## 开放侧与顺序

- +X为右侧，-X为左侧。
- +Y为下侧，-Y为上侧。
- +Z为上方。

开放侧表示来向，例如+Y表示从俯视图下侧接近目标；不表示机械臂运动必须沿正Y。自动里外基准同样使用上述标签。选择外侧+Y时，远侧在图上方，先里后外总体从上向下推进，并满足原有支撑与跨层依赖。

## 箱子坐标与导出

界面箱子列表、新输出的装箱方案JSON、位置CSV及命令行坐标均采用左上角坐标。`position`是箱体在该坐标中的最小XYZ角点，箱子的长宽高仍为实际放置尺寸，装箱率和体积不变。工位布局中选中托盘后，XYZ编辑值表示左上角P0相对机器人基座的位置；绕Z旋转时保持P0位置不动。

历史方案文件和工位文件不会自动重写。历史方案查看时采用转换后的显示副本，轨迹数组共享；机器人回放将箱体位置转换回内部坐标，因此实际箱体、工位和轨迹不会因改原点而镜像或移动。历史短边为X的特殊方案保留其原有length/width轴含义，界面明确显示“沿记录length/width”，不伪装成已经交换长短轴。

## 与机器人坐标的关系

“X向右、Y向下、Z向上”是左手显示坐标；机器人FK、IK、刚体姿态及碰撞仍使用原有右手坐标。程序只在边界转换位置、箱体角点和方向名称，不把反射矩阵当作机器人旋转矩阵。

设托盘短边为W，内部坐标为i，显示坐标为u：点满足 `x_i=x_u, y_i=W-y_u, z_i=z_u`；宽度为w的箱体最小角点满足 `y_i=W-y_u-w`。±Y来向相互转换，X及Z不变。`base_T_pallet`仍属于内部右手坐标，工位保存时另行记录显示P0的基座位置。

新方案的 `coordinate_system.frame` 为 `top_left_x_right_y_down_z_up`，并记录转换公式。机器人报告中的世界TCP姿态、关节轨迹、抓取 `box_T_tcp` 不变；其中方向标签转换成显示坐标，而底层几何字段明确标记内部坐标。原始未完成诊断和独立托盘检查点保留内部坐标并带坐标系标签，不能直接当作显示坐标或整批完成结果。

低层算法API默认仍接受内部坐标；需要传入显示来向时，为 `ApproachConfig` 指定 `coordinate_frame=PUBLIC_FRAME`，算法边界会且只会转换一次。桌面和命令行已默认采用显示来向，无需手工换算。

本次没有运行668箱生产搜索或真实模型整批路径试算；代码更新在重启程序后生效。
