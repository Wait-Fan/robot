# Ananno 2025 inherited research implementation

Goal: 在用户独立2025目录继承2024基线，初步实现2025固定开放方向数字模型，保留完整溯源。

Architecture: 继承现有PaperTwoPhasePacker，增加构层工厂扩展点及GA候选方案可执行序列评估；2024模式不启用新约束。固定方向AABB扫掠生成遮挡依赖、支撑依赖，迭代展开无环依赖并重放旧约束。第一阶段不能排成可执行序列的托盘箱体退回GA，作为明确的实现假设。

Source: research/ananno2025.txt，论文2.2–2.4节，DOI10.1016/j.ifacol.2025.09.338。轻量开放侧模型并非完整URDF/IK/关节轨迹模型；原文Algorithm1/2的伪代码未在本地PDF抽取文字中出现，不能宣称逐行等价。待后续RobotStudio/实物验证。

Interfaces: ApproachConfig(open_direction='+Z'); OpenDirectionModel.blockers(candidate,placed); executable_sequence(placements,pallet,config,approach,cancelled)；RobotTwoPhasePacker(pallet,config,approach)。输出robot_diagnostics和provenance。CLI --algorithm robot2025 --open-direction；新GUI默认2025，原GUI类保留供2024测试。
