# 局部路径恢复与未完成状态

本次修改处理“某箱规划未完成，导致整盘退回GA，大量箱子反复重排”的问题。跨层先里后外、边缘对齐抓取、预放置和真实碰撞检查保持启用。

## 恢复路径

平滑器保留输入的原始绕障路径。捷径路径经过速度/加速度时间参数化和曲线碰撞检查后仍不通过，则恢复原始路径重新参数化和检查。仅在重新检查通过时接受；必要时在原始路径拐点减速至停止，保持关节位置、速度、加速度连续。原始路径也不通过时继续本段局部规划重试，不绕过碰撞或关节限位。

## 局部重试

默认在第一次失败后再重试2次，共最多3次。设置位置：工位布局 → 验证与计算 → 单段失败后局部重试。单次路径预算仍使用原设置；每箱预算及总任务时限始终生效，不因重试而重新计时。

重试从同一操作的原始关节状态、场景和携箱附件开始，不重复提交已成功的阶段。搬运/接近取箱段变换IK种子与RRT种子，并尝试其他目标关节分支；找不到替代分支时，重新检查并复用此前已求出的有效目标构型，用新的RRT种子继续搜索。笛卡尔放置/撤离段逐步加密采样。完整经过IK、路径及平滑曲线检查后才提交阶段。

## 区分失败

- IK搜索预算耗尽或未找到解：未知，不代表数学上不可达。
- IK收敛但目标构型发生碰撞：记录碰撞对，仍可尝试其他构型。
- RRT搜索预算/迭代耗尽：未知，不直接判定垛型不可行。
- 平滑失败：细分曲线碰撞、关节限位、笛卡尔末段偏差等原因。
- 箱体几何、支撑等硬约束已明确失败：可以返回布局搜索。

局部重试仍未通过时，任务结束为“机器人规划未完成”（运行状态 `validation_pending`），不发布完整可执行方案，也不把未知规划结果送回GA重排。达到单箱/整次时限仍使用超时未完成状态。此行为避免循环重算，但不保证任意数据在默认预算内都能找到可执行路径。

运行输出目录中的 `robot_validation_pending.json` 保存当前未完成托盘的已完成箱体前缀、部分阶段、失败动作、重试记录、各次失败时的原始候选路径、当前关节/携箱状态、放置箱体和碰撞环境，用于后续针对该箱诊断。此前完整验证通过的独立托盘另存入 `robot_verified_pallets/<上下文键>.json`，保存箱体布局及完整运动报告，标记 `packing_completed=false`，并由未完成诊断引用。这些文件不是完整装箱结果，不会自动当作已验证缓存载入。此前完整结果和历史画面保留；进程内成功前缀/整盘缓存继续按完整上下文复用。

代码更新需要重启程序才能生效；已经启动的计算仍使用其加载时的旧代码。本次仅做确定性单元和界面回归检查，没有启动新的668箱搜索或真实模型整批路径试算。
