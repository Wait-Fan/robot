# 跨层顺序、边缘对齐吸盘与预放置轨迹

桌面2025入口和命令行默认使用 `preplace_optimized`。已有结果保持原始顺序、抓取位置和轨迹；需要重新计算才能使用新规则。

## 顺序

原来的高度优先排序只保证同层先里后外，会出现“底层远侧—底层近侧—上层远侧”。新规则对每个托盘建立支撑及深度依赖：完全位于远侧深度区间内的箱体，包括上层箱体，必须先于近侧区间箱体。下层实际接触的支撑箱必须先放。

深度区间重叠的跨区大箱可能同时支撑多个箱体，此时满足支撑依赖，再按远侧优先选择。如果支撑与深度约束形成循环，拒绝当前垛型，返回搜索；不改成先外后里。机器人完整校验必须有明确的里外基准；自动判断不唯一时须在装箱设置中选择外侧。

## 运动

抓取 → 沿世界Z短抬升 → 携箱避障搬运 → 预放置点 → 下降或斜下降 → 释放撤离。

- 默认短抬升80 mm、预放置点高于目标150 mm、水平偏移100 mm。
- +Z使用目标正上方预放置点；±X/±Y使用短水平偏移且有正Z高度的预放置点，最后斜下降。
- 开放侧限制最终接近候选，不再要求从整个托盘边界等高水平滑入。几何阶段只产生候选，真实路径必须由完整机器人模型检查。
- 搬运段使用关节空间RRT-Connect及碰撞检查后的捷径，允许曲线路径。比较时间预算内完整通过的候选，按预计搬运、放置及撤离时间选择；这是预算内最好候选，不是数学上的全局最优证明。
- 参数在“工位布局 → 验证与计算”修改。预放置高度是相对最终TCP，不是要求先升到整垛最高点。

## 吸盘

矩形吸盘外包络默认使用 `occupied_edges`：按已放箱邻接情况分别确定X、Y的占用侧，把对应吸盘边与箱边对齐，超出的部分向空侧伸出。优先避让高于当前箱顶的邻箱。无邻箱时根据机械臂外侧及工位位置选择方向。两侧同时被夹住且吸盘放不下时仍拒绝。

自动对齐要求吸盘水平并与箱边平行；手动XY抓取偏置由逐箱对齐结果替代，Z标定偏置保留。抓取点、携箱附件、目标包络、快速筛选及动画共用同一 `box_T_tcp`。此变换及所选对齐边保存在每箱运动记录的 `grasp` 中。旧结果无此记录时，仍按旧中心吸取回放。

“工位布局 → 抓取与预览”可切换回中心吸取。600×800 mm为用户提供的吸盘面尺寸；250 mm工具高度仍为暂定值，程序不会在本次代码更新中修改现场工位文件。

## 平滑与记录

新轨迹使用 `piecewise_quintic_c2`：段内关节速度连续、加速度连续，抓取/释放等操作边界保留停止。每个细分路径采样点不再强制停车。按关节速度、加速度限制伸缩时间，并检查曲线关节极值及离散碰撞；笛卡尔末段保留原有采样点，限制平滑曲线偏离。平滑不安全时减小过渡速度，无法通过则拒绝该路线，不直接播放未经检查的曲线。

回放使用保存的关节位置、速度和加速度，旧 `rest_to_rest_cubic` 结果保持原三次插值。碰撞检查仍是按关节分辨率离散检查，不是连续碰撞检测。缓存包含顺序、开放侧、工具、场景及本次轨迹实现版本，不会把旧抓取方式的路径当作新路径复用。

本次修改只进行确定性单元及界面回归检查，未执行668箱装箱搜索或新的真实模型整批路径试算。
