# 单托盘箱子数据与机械臂动态回放

## 箱子列表

点击总览中的托盘卡片，或在“单托盘 / 回放”页选择托盘后，“箱子列表”仅显示该托盘已装箱数据，标题注明托盘编号与箱数。坐标CSV导出使用当前表格中的选中托盘数据。总览继续显示筛选范围内的垛型；未放置箱子没有所属托盘，仍在“失败列表”集中展示。

## 打开动态机械臂回放

1. 在“工位布局”配置并应用机械臂、吸盘、托盘、取箱台和障碍物。
2. 勾选“机器人完整校验”，完成一次计算并保存结果。
3. 点击该托盘卡片右上方的“机械臂回放”，或单托盘页的同名按钮。

原来的放大按钮和垛型逐箱预览保留。新窗口播放计算时保存的关节轨迹，显示机械臂、吸盘、源箱、正在携带的箱子和已经放置的箱子。界面展示当前箱号、动作阶段、接近方向、关节角和轨迹时间。

支持播放/暂停、重置、上一箱/下一箱、最终状态、拖动进度和0.25—20倍速。拖动视角旋转，滚轮缩放，双击适应画面。可勾选“吸盘半透明”观察大吸盘下方的箱子；该选项只改变显示，不改变碰撞模型。

抓取完成后，箱体随TCP与抓取变换运动；释放后留在规划位置。拖动时间前进或回退都会重建相应装箱状态，已放箱体不会继续随机械臂移动。回放只显示所选托盘的操作，其他托盘独立处理。

## 历史结果与文件

回放读取同一结果目录中的`robot_scene_snapshot*.json`，核对工位、URDF、网格、工具及关节名称是否与轨迹匹配。请保留整个结果文件夹和项目机械臂模型文件。不会用当前新改的工位替代计算时的历史工位。

只有几何筛选、缺少关节轨迹、缺失工位快照或模型已改变的结果，会提示启用完整校验重新计算，不生成示意机械臂动作冒充规划轨迹。

机器人窗口是只读离线回放，没有连接真机。回放使用后端保存的静止到静止三次插值时间，与界面“算法计算时间”分开。

## 显示改善

历史记录下拉框使用独立的深色文字和蓝底白字选中样式，并支持完整文件路径提示。垛型画布以加粗实线标注托盘底部边界，以较深虚线标注立柱和限高框。


## 计算期间浏览

装箱计算期间，可以打开历史结果或结果文件、切换托盘、查看箱子表、旋转缩放垛型、导出当前查看的坐标，以及播放已保存的机械臂轨迹。浏览使用独立结果数据，不改变本次任务启动时捕获的输入、尺寸和配置。

本次任务的输入选择、算法参数、工位及完整校验开关继续锁定，也不能重复启动任务。“停止”按钮仍然可用。

计算期间切到历史结果时，运行状态和进度继续显示后台任务。计算完成后保留当前历史画面，点击“查看本次结果”载入新结果；如果没有切换结果，完成后照常自动显示新结果。打开损坏的历史文件只提示读取失败，不把后台任务标记为失败。

模型导入与XML模板导出的短阶段使用互斥保护，避免回放和后台计算加载不同机器人时串用模型；完成加载后的模型和关节状态各自独立。三维绘制和回放会共享电脑算力，计算耗时可能增加。
