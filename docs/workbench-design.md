# 历史Tkinter工作台设计

此文件保留先前Tk版设计记录。当前默认界面已于2026-10-29迁移为PyQt5 v0.4.0，参见 `superpowers/plans/2026-10-29-pyqt-workbench.md` 与README；本文中的Tk/无图形依赖描述不再适用于当前桌面入口。

用户已于本轮确认按精简版 zhuang 工作台开始改造；无需再次确认同一方案。

目标：`python main.py` 打开标准库 Tkinter 工作台，在本地选择输入、运行现有阶段性 Ananno Phase 2 算法、查看三维逐箱动画和坐标、回看历史结果。无数据库、第三方图形依赖、WCS 或企业订单约束。

布局：深色顶部操作栏；左侧文件、可选论文订单、托盘与支撑参数、进度；中间三维总览（每页六盘）、单盘交互和结果/未装箱表；右侧总体与当前盘统计；底部折叠日志。

输入：论文 CSV 按 Order 选择一次求解任务；普通 CSV 和精简 JSON 为整文件求解。JSON 导入托盘尺寸。所有尺寸单位保持一致。

计算：threading.Thread 中执行现有固定序列算法，queue.Queue 把事件送回主线程处理；Tk 对象只在主线程使用。只增加可选进度回调和协作取消检查，不改候选和可行性规则。停止后不发布半成品结果。新计算期间保留上一结果，成功后整体替换。

输出：每次运行独立时间戳目录，内含现有 JSON/CSV 与 PNG。完成自动载入。历史由本地结果文件扫描产生。打开错误文件时保留当前有效结果。空结果和全部超大箱也能展示。

三维：标准库 Tk Canvas 使用正交投影与深度排序绘制长方体，支持拖动旋转、滚轮缩放与视角复位。总览分页，单盘放大、按箱/箱型/高度着色、标签、播放/暂停/前后步/最终。PNG 通过标准库栅格化与 zlib 输出。动画只展示已有放置序列，不是机器人轨迹验证。

验证：服务层输入、取消、结果校验、回调测试；Tk 真实事件循环验证计算、表格和动画联动；全套回归；公开订单真实运行；PNG 视觉检查。使用用户实际解释器 Python 3.13.7；在未安装任何第三方图形库的环境验证。
