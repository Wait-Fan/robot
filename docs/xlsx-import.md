# XLSX 导入（2026-10-29）

目标：现有 PyQt5 文件选择和 CLI --input 直接接收 .xlsx，共用一个只读解析器，不改装箱算法。

使用 openpyxl 的 read_only/data_only 模式，不要求安装 Excel，不保存或修改原表。优先读取“最终挑选结果”；其他工作簿在前20行识别尺寸表头，多个候选表时明确报错，避免把参考表合并为货物。

必要字段仅长宽高；支持 length/width/height 和箱子长/宽/高等表头。箱号、箱型、重量可选，缺少箱号自动生成，缺少重量为0并提示。quantity/数量/箱数/target_num 表示箱数，默认1；实际包装数量是业务字段，忽略。销售订单、Case占用数、BMS表不参与分组/约束。

所有尺寸为有限正数，重量有限非负，箱数为正整数；异常报告表名和行号，不跳过坏行。托盘长宽高一致时自动带入；混合规格保留用户设置并提示确认统一规格。
